# Eremos

A 2D game built with **Unity 6** using the **Universal Render Pipeline (URP)**.

## Project Details

- **Engine Version:** Unity `6000.3.10f1`
- **Render Pipeline:** Universal Render Pipeline (URP)
- **Input System:** New Input System (`com.unity.inputsystem`)
- **Version Control:** Git + Git LFS

## Getting Started

### Prerequisites

1. Install [Git](https://git-scm.com/) and [Git LFS](https://git-lfs.github.com/).
2. Install [Unity Hub](https://unity.com/download) and **Unity 6000.3.10f1** (or compatible Unity 6 release).

### Cloning the Repository

Because binary game assets are managed with Git LFS, make sure Git LFS is installed before cloning:

```bash
git lfs install
git clone https://github.com/zackncody/Eremos.git
```

### Opening the Project

1. Open **Unity Hub**.
2. Click **Add** -> **Add project from disk**.
3. Select the `Eremos` folder.
4. Ensure the editor version is set to `6000.3.10f1`.
5. Open the project.

## Repository Structure

- `Assets/` - Game scripts, scenes, sprites, audio, and prefabs.
- `Packages/` - Unity package manifests and dependencies.
- `ProjectSettings/` - Project-wide settings (tags, physics, input, graphics, etc.).
